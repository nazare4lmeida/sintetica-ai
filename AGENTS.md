# Notas para agentes

Projeto TanStack Start (React 19 + Vite). Convenções:

- Rotas em `src/routes` (file-based routing).
- Código somente-servidor em arquivos `*.server.ts` e dentro de server functions.
- Estilos com Tailwind CSS 4; componentes base no padrão shadcn/ui em `src/components/ui`.
- Variáveis de ambiente no `.env` (veja `.env.example`).
